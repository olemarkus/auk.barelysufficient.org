Styr din Auk-hage via Homey. Appen snakker direkte med enheten over Bluetooth, så du trenger en Auk med Bluetooth, som Auk Mini 2.

Via appen kan du slå lyset på eller av, dim lyset, eller la det følge en av vekstmodusene. Bytt vekstmodus mellom Urter og salat, Frukt og grønt og Sakte, og velg når lyset skal slås på hver dag.

Du kan styre Auk-enheten enten direkte via appen eller via flows.
